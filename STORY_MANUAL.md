## 🎯 ОБЗОР СЮЖЕТНОЙ ВЕТКИ

### Основная концепция
Бот представляет собой **образовательную RPG-игру** для изучения Java коллекций через интерактивный сюжет в стиле древнего Рима.

### Главные персонажи
- **БайтФордж** — мудрый наставник, создатель симуляции
- **Итераториус** — командир, проводник в мир ArrayList
- **Аррейн** — противник, олицетворяющий ArrayList
- **Пользователь** — новобранец-программист

### Сюжетные ветки
1. **Создание персонажа** — выбор типа героя
2. **Путь программиста** — введение в мир Java
3. **ArrayList** — основная боевая симуляция

## 👥 ПЕРСОНАЖИ

### 1. Personage1 — "Кодыч" (Аналитик)
```
🏆 Level: 0 → 1
⚡ Энергия: 8
⭐ Очки достижения: 0 → 50
💲 Деньги: 0 → 450
⌚ Сопротивление дедлайну: 90 → 90
📊 Аналитика: 110 → 133-149
```

**Особенности:**
- Специалист по анализу кода
- Находит скрытые связи в коде
- Привык работать под давлением сроков

### 2. Personage2 — "Флой" (Коммуникатор)
```
🏆 Level: 0 → 1
⚡ Энергия: 8
⭐ Очки достижения: 0 → 50
💲 Деньги: 0 → 450
🔍 Точность кода: 140 → 140
💬 Коммуникация: 120 → 143-159
```

**Особенности:**
- Мастер общения с кодом
- Находит баги даже в километре кода
- Комментарии для него не баг, а квест

### 3. Personage3 — "Оптимизатор" (Технарь)
```
🏆 Level: 0 → 1
⚡ Энергия: 8
⭐ Очки достижения: 0 → 50
💲 Деньги: 0 → 450
🔍 Точность кода: 130 → 130
⚙️ Процесс оптимизации: 160 → 183-199
```

**Особенности:**
- Переписывает код так, что компилятор удивляется
- Оптимизация — его страсть
- Код должен быть не только рабочим, но и красивым

### Ключевые файлы:
- `StoryStartService.java` — основная логика
- `PersonageCreationService.java` — создание персонажа
- `PersonageService.java` — управление персонажами

## 🏗️ ТЕХНИЧЕСКАЯ АРХИТЕКТУРА

### Основные компоненты:

#### 1. StoryStartService
- **Назначение:** Создание персонажа и начальная сюжетная линия
- **Ключевые методы:**
  - `handleStart()` — обработка команды /start
  - `createPersonage()` — создание персонажа
  - `ByteFordjProgrammer()` — диалоги БайтФорджа

#### 2. ArrayListStory (фасад)
- **Назначение:** Маршрутизация команд ArrayList
- **Ключевые методы:**
  - `handleMessage()` — обработка сообщений
  - `commandsMap` — карта обработчиков команд

#### 3. StatService
- **Назначение:** Управление статами персонажей
- **Ключевые методы:**
  - `generateRandomReward()` — генерация случайных наград
  - `applyStatChanges()` — применение изменений
  - `getIndividualStatForCharacter()` — индивидуальные статы

#### 4. MessageService
- **Назначение:** Создание сообщений
- **Ключевые методы:**
  - `createBattleMessage()` — боевые сообщения
  - `createResultMessage()` — сообщения с результатами
  - `createTheoryMessage()` — теоретические сообщения

#### 5. BattleActionService
- **Назначение:** Обработка боевых действий
- **Ключевые методы:**
  - `processTryCatchAction()` — обработка защиты
  - `processAnalysisAction()` — обработка анализа
  - `processInsertBeginningAction()` — обработка атаки

#### 6. ArrayListSchedulerService
- **Назначение:** Планирование событий
- **Ключевые методы:**
  - `sendTheoryWithAutoDelete()` — теория с автоудалением
  - `sendInsertBeginningResult()` — отложенные результаты
  - `scheduleEvent()` — планирование событий

#### 7. ArrayListTheoryService
- **Назначение:** Теория и диалоги
- **Ключевые методы:**
  - `formatArrayListInfo()` — теория ArrayList
  - `createEnemyMessages()` — сообщения противников

### База данных:
- **UserEntity** — пользователи
- **PersonageEntity** — персонажи
- **Статы:** achievement_points, currency, analytics, optimization, code_accuracy, communication, humor

### Логирование:
- **SLF4J** — для всех сервисов
- **Уровни:** INFO, DEBUG, ERROR
- **Контекст:** chatId, userId, действия
